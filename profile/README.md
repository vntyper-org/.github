# vntyper-org

Home of **VNtyper** and related tools for detecting variants in the *MUC1* coding VNTR (ADTKD-MUC1) from short-read sequencing data.

| Repository | Purpose |
|---|---|
| [VNtyper](https://github.com/vntyper-org/VNtyper) | Genotyping pipeline (CLI, Docker, PyPI) |
| [vntyper-data](https://github.com/vntyper-org/vntyper-data) | Versioned, checksummed reference bundles |
| [vntyper-online-backend](https://github.com/vntyper-org/vntyper-online-backend) | Deployment of the web service |
| [vntyper-online-frontend](https://github.com/vntyper-org/vntyper-online-frontend) | Web interface |

Web service and docs: [vntyper.org](https://vntyper.org/) · [documentation](https://vntyper-org.github.io/VNtyper/)

Research use only.
