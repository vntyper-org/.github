# vntyper-org

Open tools for the *MUC1* coding VNTR (ADTKD-MUC1): genotyping variants from short-read sequencing data, and simulating MUC1 haplotypes and reads to benchmark them.

| Repository | Purpose |
|---|---|
| [VNtyper](https://github.com/vntyper-org/VNtyper) | Genotyping pipeline (CLI, Docker, PyPI) |
| [vntyper-data](https://github.com/vntyper-org/vntyper-data) | Versioned, checksummed reference bundles |
| [vntyper-online-frontend](https://github.com/vntyper-org/vntyper-online-frontend) | Web interface at vntyper.org |
| [vntyper-online-backend](https://github.com/vntyper-org/vntyper-online-backend) | Deployment of the web service |
| [MucOneUp](https://github.com/vntyper-org/MucOneUp) | MUC1 VNTR haplotype and read simulator |

Web service: [vntyper.org](https://vntyper.org/) · Docs: [VNtyper](https://vntyper-org.github.io/VNtyper/) · [MucOneUp](https://vntyper-org.github.io/MucOneUp/)
